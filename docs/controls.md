# Controls

## On-screen controls

Click a menu item to open it or a track to play it. In **Tracks**, **UP** and
**DOWN** move between pages of four tracks. **BACK** returns to Home.
**PREV**, **PLAY/PAUSE**, and **NEXT** control playback. The **−** and **+**
buttons change the player's volume by 10 percentage points.

A click activates a control when the primary button is released on it.
Dragging across the screen cancels the action. A touchscreen can use these
controls if the graphical session delivers taps as primary pointer clicks.
Use the [Nura guide](phone.md) to set up a test session.

## Keyboard

Focus the player window to use these keys on a laptop, in QEMU, or with
a keyboard connected to a phone.

| Key | Action |
| --- | --- |
| `j` or Down Arrow | Move down one item |
| `k` or Up Arrow | Move up one item |
| Enter or keypad Enter | Select the current item |
| `b` or Escape | Return to Home |
| `p` or Space | Play or pause |
| Left / Right Arrow | Seek backward / forward by five seconds |
| Shift+Left / Shift+Right | Play the previous / next track |
| `h` / `n` | Play the previous / next track |
| `+` / `=` or keypad `+` | Increase player volume by 10% |
| `-` or keypad `-` | Decrease player volume by 10% |
| `q` or Ctrl+C | Quit |

The player's volume is saved between runs. Scroll input is reserved for menu
navigation. Phone volume buttons are planned work.

## Playback settings

In Settings, use the row controls or `j`/`k` and Enter. Update Library and
Equalizer keep their existing behavior. Volume increases by 10 with Enter;
the global minus/plus controls adjust it in either direction. Repeat cycles
Off → All → One → Off; Shuffle toggles Off/On. All modes are saved between runs.
Repeat One applies to automatic completion, not manual Next/Previous. Manual
navigation wraps in the current library/shuffled order. See
[repeat and shuffle](repeat-shuffle.md) for the full behavior.
