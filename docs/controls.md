# Controls

Focus the player window to use these keys on a laptop, in QEMU, or with
a keyboard connected to a phone. `Scroll` is reserved for menu navigation;
use the arrow keys below for playback controls.

| Key | Action |
| --- | --- |
| `j` or Down Arrow | Move down one item |
| `k` or Up Arrow | Move up one item |
| Enter or keypad Enter | Select the current item |
| `b` or Escape | Return to Home |
| `p` or Space | Play or pause |
| Left / Right Arrow | Seek backward / forward by 5 seconds |
| Shift+Left / Shift+Right | Play the previous / next track |
| `h` / `n` | Play the previous / next track |
| `+` / `=` or keypad `+` | Increase player volume by 10% |
| `-` or keypad `-` | Decrease player volume by 10% |
| `q` or Ctrl+C | Quit |

The volume shortcuts adjust the player's own volume, which is saved between
runs. Touch navigation and phone volume buttons are planned work. See the
[Nura guide](phone.md) for setting up a test session.
